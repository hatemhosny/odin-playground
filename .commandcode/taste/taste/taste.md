# Taste
- Prefers small browser tools delivered as a single static HTML file that pulls libraries from a CDN (e.g. LiveCodes) — no build step, bundler, or framework. Confidence: 0.6
- When building a UI, wants the styling to match a specific existing site the user names (e.g. odin-lang.org/docs) instead of a generic or invented look. Confidence: 0.6
- Calls out an existing analogous project as the template to model a new one on (e.g. crystal-playground → new odin-playground). Confidence: 0.5
- When handing off to an external/embedded app (e.g. "Open in LiveCodes"), wants app-specific settings like theme, display mode, and autoupdate stripped so the destination uses its own defaults instead of inheriting ours. Confidence: 0.5
- Keeps personal dev projects under `D:\DevWork\` with kebab-case, purpose-based folder names (e.g. `crystal-playground`, `odin-playground`). Confidence: 0.5
- Specifies requirements by pointing at concrete references — existing codebases, GitHub issues, and official docs/tutorial URLs — and expects those to be consulted. Confidence: 0.5
